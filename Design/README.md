The Figma guide records the brand identity, colour palette, typography, and voice. It is a branding reference rather than a set of app screen designs. The local `.fig` file is a snapshot saved from Figma Desktop; use the live file for current edits.

## Identity

- Tally's flat mark combines a floor plan and magnifier. Use ink on white or white on ink, with clear space equal to the magnifier radius.
- Keep the wordmark simple and unadorned. Use the production [Icon Composer source](../Tally/Tally/AppIcon.icon) for the iPhone app icon; the flat mark is for documents and other brand materials.
- Avoid decorative gradients, added shadows, and generic house silhouettes.

## Colour

| Role | Light reference | Dark reference | Use |
| --- | --- | --- | --- |
| Canvas | `#FFFFFF` | `#000000` | Main background |
| Ink | `#1C1C1E` | `#FFFFFF` | Mark and prominent text |
| Grouped surface | `#F2F2F7` | `#1C1C1E` | Supporting surfaces |
| System blue | `#007AFF` | `#0A84FF` | Links and primary actions only |

These hex values are brand references. In iOS, use dynamic semantic system colours so Dark Mode and increased contrast adapt correctly. The Figma file retains Light, Dark, and increased contrast colour variables.

## Typography

- Use **San Francisco (SF Pro)** through iOS system text styles. Regular is the reading weight; Semibold marks hierarchy and key figures. Do not bundle SF Pro with the app.
- Use sentence case, comfortable spacing, and monospaced digits for prices and dimensions. Respect Dynamic Type on iPhone.
- Figma's renderer did not display SF Pro in our specimens, so the visible guide uses Inter as a preview proxy. The file retains named SF Pro text styles for handoff. Inter is not the prescribed app font.

## Voice and imagery

Write with precision and restraint. Say “planning estimate” until an artisan has drafted a quote, and disclose when measurements need verification. Prefer real rooms, materials, and labelled plans in natural light. Avoid synthetic interiors and claims of certainty that the available data cannot support.
